# 07. 安全与脱敏边界

## 1. 仓库允许包含

- InStock 上游公开信息；
- 脱敏架构和目录；
- 只读健康检查命令；
- 通用数据契约、质量规则和指标公式；
- 合成测试数据；
- 不含真实收件人的提醒流程；
- 故障和验收方法。

## 2. 仓库禁止包含

- 私有选股/交易规则、阈值、权重和提示词；
- 候选清单、持仓、交易记录和回测结论；
- 数据源付费凭据；
- Token、Cookie、密码、私钥和完整环境变量；
- 微信收件人、账号和会话标识；
- 完整 Compose 展开配置；
- 生产数据库导出；
- 私有研究目录内容；
- 新闻分析任务、数据或流程。

## 3. 网络边界

- 9988 和 6701 只绑定回环地址。
- MariaDB 不发布宿主机端口。
- 本地访问 Web 使用 SSH 隧道。
- `instock_client.py` 默认拒绝非回环主机。
- 如需远程代理，由运维显式开启 `allow_remote`，并确保 TLS、认证和审计已经存在。

## 4. 接口边界

- 只使用 GET。
- 模块名必须在白名单。
- 默认阻断空白名单。
- 请求有超时，响应有字节上限。
- 不调用 InStock 写控制接口。
- 不直接在生产数据库运行 Agent 生成的 SQL。

## 5. 日志脱敏

日志保留：

- 时间；
- 状态码；
- 数据集名；
- `as_of`；
- 行数；
- SHA-256；
- 错误类型。

日志删除或掩码：

- Authorization；
- Cookie；
- query 中的秘密；
- 收件人；
- 候选内容；
- 真实策略参数；
- 完整原始响应中的敏感字段。

## 6. Git 发布前检查

```bash
git status --short
git diff --cached --stat
git diff --cached

rg -n --hidden \
  '(gho_|github_pat_|AKIA|BEGIN .*PRIVATE KEY|password\s*[:=]|token\s*[:=]|cookie\s*[:=]|wxid_)' \
  . -g '!.git/**'
```

命中示例字段名时人工判断；命中真实值时停止发布并轮换秘密。

建议额外启用 GitHub secret scanning 和 push protection。

## 7. 变更权限

| 动作 | 默认 |
|---|---|
| 只读健康检查 | 允许 |
| 合成数据测试 | 允许 |
| 保存脱敏原始快照 | 允许 |
| 重启应用 | 需运维授权/流程 |
| 改数据源或 schema | 需所有者批准 |
| 改主动提醒 | 需所有者批准 |
| 读取私有策略 | 禁止，除非所有者专项授权 |
| 开启交易 | 禁止 |
| 对公网开放服务 | 禁止 |

## 8. 事故响应

疑似泄密：

1. 立即停止 push/分享；
2. 记录受影响文件和 commit；
3. 轮换可能泄露的秘密；
4. 从当前分支删除不够，按安全流程清理 Git 历史；
5. 检查 GitHub Actions、Artifacts、缓存和日志；
6. 记录修复和预防措施。

疑似数据误导：

1. 阻断下游；
2. 标记 stale/unknown；
3. 保存数据日期和刷新证据；
4. 修复后重算；
5. 对已发送结果发更正或恢复通知。
